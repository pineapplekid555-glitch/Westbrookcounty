# Westbrook County website

A responsive, single-file static website with:
- Homepage and department cards
- Release ribbon linking to a countdown page
- Live countdown to 2 October 2026, 9:00 PM UK time (BST)
- Custom Liveries links to the supplied Google Drive folder
- Mobile navigation

## Preview locally
Open `index.html` in a modern browser.

## Deploy for free
Upload `index.html` to a GitHub repository and connect it to Cloudflare Pages, or use any static website host. Set the build command to blank and the output directory to `/` (repository root). Then add your custom domain in the host's domain settings and follow its DNS instructions.

Replace placeholder community/game links or text with your official details before launch.
