Server API

Control your own private server from a Discord bot or a website. Plain-English guide, no coding needed to get started.

Start here

The Server API lets you control your own Westbrook County private server from a Discord bot or a website, for example to send an announcement, kick someone or see who is online.

What you need

  • A Westbrook County private server with the Server API pack (Settings → Upgrade Packs).
  • A server key, which works like a password for your server.
  • A bot or website that can send web requests. New to this? The steps below use a free website called Hoppscotch, so you don't need to code.

Try it in 3 steps

  1. Get your key. In-game, open your private server's Settings, scroll to Server API Pack and press Generate key. Copy it straight away, because it is shown only once. Keep it private.
  2. Check it works. Go to hoppscotch.io, fill in the request like this and press Send:
SettingValue
MethodGET
URLhttps://westbrookcounty.co.uk/api/v1/server
Header nameserver-key
Header valueyour key

You should see your server's name and how many players are in it. If you see "offline", wait a minute and press Send again.

  1. Send a command. Change the method to POST and the URL to https://westbrookcounty.co.uk/api/v1/server/command. Add a header Content-Type with value application/json. In the body put {"command": ":h Hello"} and press Send. "Hello" pops up in-game within a couple of seconds.

Endpoints

Every address starts with https://westbrookcounty.co.uk/api/v1 and every request needs your server-key header. "GET" means you are asking for information; "POST" means you are sending something.

What you wantMethodAddress ending
Server infoGET/server
Who is onlineGET/server/players
Everything that happened (joins, leaves, team changes, commands)GET/server/logs
Joins and leaves onlyGET/server/joinlogs
Team changes onlyGET/server/teamlogs
Commands sent through the API and how they wentGET/server/commandlogs
Run a commandPOST/server/command

The server must be running for server info, players and commands. The logs work even when it is off.

Server info /server

FieldWhat it is
NameYour server's name
OwnerId, OwnerNameThe owner
CoOwnerIdsCo-owners' Roblox user ids
CurrentPlayers, MaxPlayersHow many are in, and the limit
JoinKeyThe join code
TeamBalanceHow many players are on each team
AgeSecondsHow old this information is, in seconds

Players /server/players

One entry per player (up to 100):

FieldWhat it is
Name, DisplayNameRoblox username and display name
UserIdRoblox user id
TeamTheir team
PermissionTheir permission level in your server

Logs

Log addresses give the newest entries first and keep the last 400. Add options to the address, for example /server/logs?limit=10:

OptionWhat it does
limitHow many entries, from 1 to 100 (default 50)
beforeAn entry Id; shows only older entries, to go back through the list
typeOnly some kinds, like type=join,leave. Choices: join, leave, team, command

Each entry has an Id, a Timestamp and a Type (Join, Leave, Team or Command). Join and leave entries show the player's Name and UserId. Command entries show the Command, whether it worked (Success) and the Result.

Run a command /server/command

Send a POST with the header Content-Type: application/json and a body like this (up to 300 characters):

{ "command": ":h Hello everyone" }

You get back Success and a commandId. That means the command was sent, not that it has run. The game runs it within a couple of seconds, and you can see how it went in /server/commandlogs.

Commands

Send these as the command text. A player can be a username, a display name, the start of either, or a user id.

CommandEffect
:h <message>Show a message to everyone (also :m, :message, :announce). Filtered by Roblox.
:pm <player> <message>Private message to one player.
:kick <player> [reason]Remove a player. The owner and co-owners can't be kicked.
:heal <player>Restore a player's health.
:time <cycle|dawn|day|dusk|night>Set the time of day.
:weather <clear|cloudy|rain|storm|fog|dynamic>Set the weather.
:peacetime <off|normal|strict>Peacetime mode.
:priority <0-3>How many priorities may run at once (0 turns them off).
:set <setting> <value>peacetime, priorityMax, priorityCooldown, wantedDecay, civilianWeapons, timeOfDay, weather, streetLamps, fuelMultiplier, damageMultiplier, nameTags.
:helpLists these in the command log.

Settings changed with :time, :weather, :peacetime, :priority and :set are saved to your server, the same as the in-game settings panel.

Keys, limits & errors

Keeping your key safe

  • Treat the key like a password: anyone who has it can run commands on your server.
  • Keep it in an environment variable or secret store, never in front-end code, a public repository or a Discord message.
  • If it leaks, press Generate key again in your server settings. The old key stops working immediately.
  • Only let trusted staff use any bot command that sends in-game commands.
  • Web pages cannot call the API directly (browsers are blocked). Call it from a bot or a website's back-end.

How fresh the data is

  • Information comes from your server's last report, not live: about every 15 seconds while you are using the API, otherwise about once a minute.
  • If the server has not reported for about 15 minutes, server info, players and commands answer 422 (offline). Logs still return the last 400 entries.
  • Commands are queued, not confirmed. Roblox messaging can rarely lose a message, so resend if nothing happens.

Limits

20 requests per 10 seconds and 10 commands per minute, per key. Going over gives a 429 with a Retry-After header (seconds to wait).

Error codes

Errors look like {"code": 2002, "message": "Invalid server-key."}

HTTPCodeMeaning

4012000No server-key header
4032002Key is wrong, or was regenerated

Connecting tools

Bots and dashboards (such as Melonly) that can talk to a server API usually ask for a base URL, the name of the key header, and your key.

SettingValue
Base URLhttps://westbrookcounty.co.uk/api/v1
Key header nameserver-key
Key header valueYour server key (starts with wbk_)
Other headersNone for reading. For commands, also Content-Type: application/json
  • The layout and field names follow the ER:LC server API (Name, CurrentPlayers, Player as Name:UserId, Team, Permission), so tools built for that style are the closest fit.
  • There is no separate global key. Your server key is the only key you need.
  • A tool can only use this API if it lets you set a custom URL. Tools hard-coded to another game's address will not connect.
  • Not every tool has been tested with this API yet.

Map & site APIs

These are public: no key is needed. They live at https://westbrookcounty.co.uk and the two map addresses can be used from any website.

AddressWhat you get
GET /api/mapsMap image links, plus the image size, studs per pixel and map edges
GET /api/map-pointsPlaces and streets with their positions in the game world
GET /api/statsLive Roblox stats for the game
GET /api/statusWebsite and API status

Map images

  • /assets/maps/westbrook_blank.png: plain map, transparent outside the island
  • /assets/maps/westbrook_labelled.png: map with street names and places
  • /assets/maps/westbrook_blank_small.png: smaller plain map

Marking a place on the map

/api/map-points gives each place and street with its position in the game world. /api/maps gives the image size and the edges of the map (bounds). To find a spot on the image, take how far across the map the position is and multiply by the image width, and do the same down the map for the height. The top of the image is the smallest z value.

For developers

You can skip this if you only want to try the API in Hoppscotch. It is for people building a website or bot.

Connecting a website

Keep the key in an environment variable called SERVER_KEY, never in the code or the page. Your page talks to your back-end, and the back-end calls the API.

app.post("/announce", async (req, res) => {
  const r = await fetch("https://westbrookcounty.co.uk/api/v1/server/command", {
    method: "POST",
    headers: { "server-key": process.env.SERVER_KEY, "Content-Type": "application/json" },
    body: JSON.stringify({ command: ":h " + req.body.text })
  });
  res.status(r.status).json(await r.json());
});

The same approach works in PHP, Python or a Cloudflare function: send the server-key header from the server side.

Discord bots

A bot only needs to call the same endpoints with the server-key header, for example /server, /server/players and /server/command. Restrict any command that sends in-game commands to your staff role.

Troubleshooting

SymptomLikely cause and fix
422 right after generating a keyThe server has not sent its first report yet. Wait up to a minute and try again.
422 later onThe server is not running, or has not reported for about 15 minutes. Start it and retry.
403Wrong key, or the key was regenerated. Generate a new one in your server settings.
401The server-key header is missing. Check the header name.
429Too many requests. Wait for the Retry-After seconds.
400 on a commandThe body must be JSON like {"command": ":h Hello"}, at most 300 characters.
Command accepted but nothing happensResend it, and check /server/commandlogs for the result.
502 or 503The website could not reach Roblox, or the Server API is not available right now. Try again in a minute, then ask staff in Discord.
Browser error calling from a web pageBrowsers cannot call the API directly. Call it from a bot or back-end.

Still stuck? Ask in the Westbrook County Discord. Never post your server key there; if you do, regenerate it straight away.
